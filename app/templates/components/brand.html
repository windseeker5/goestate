{# Brand mark: the "GO" square that stands in for the app icon. This exists because the same markup used to be hand-copied into the landing nav, the login hero, and the sidebar header — and the copies drifted on every axis. The landing page ended up reading "E" while everything else, including favicon.ico, apple-touch-icon.png, brand-go.svg and every PWA icon in manifest.webmanifest, read "GO". One definition here, three call sites. Rendered as text on theme tokens rather than embedding static/icons/brand-go.svg on purpose: that SVG hardcodes #111111 on #ffffff, so it would stay dark-on-light in dark mode, where --primary inverts to near-white. Not to be confused with the user avatar in the sidebar footer — that one is rounded-full and shows the signed-in user's initials.
