{# Action menu: a single "Action" button (label, a thin vertical divider, then a trailing chevron-down icon — matching the shadcn "Copy Page" split-button style) that opens a Basecoat dropdown menu of row-level actions (View, Edit, Delete, etc). This is the standard replacement for a loose row of separate buttons (View / Edit / Delete) in any data table's actions column. Usage: {% from "components/action_menu.html" import action_menu %} {{ action_menu( id="row-actions-" ~ row.id, items=[ {"label": "View", "url": url_for('detail_x', item_id=row.id)}, {"label": "Edit", "url": url_for('edit_x', item_id=row.id)}, {"type": "separator"}, {"label": "Delete", "attrs": {"class": "text-destructive", "onclick": "..."}} ] ) }} Params: id {string} Unique id, so multiple menus on one page don't collide (e.g. one per table row) — pass "row-actions-" ~ row.id. items {list} Same shape as basecoat/dropdown-menu.html.jinja's `items` param: each dict is {label, url?, icon?, attrs?} or {"type": "separator"}. label {string} Trigger button text. Default "Action". align {string} Popover alignment: "start" | "end". Default "end" (right-aligned), since this is almost always the last column in a table and should never overflow past the right edge of the viewport. The parameters below exist so this macro can also render a page-level primary CTA, not just the row-level utility menus it was written for. They all default to the row-action look, so existing call sites are unaffected. variant {string} Basecoat button variant. Default "outline" — the secondary treatment, correct for a row action. Pass "primary" for a page's main call to action. size {string} Basecoat button size. Default "sm". icon {string} Optional raw SVG placed before the label. Give it data-icon="inline-start" so Basecoat tightens the leading padding for it. divider {bool} Thin rule between label and chevron. Default true. Pass false for a plain dropdown trigger: the divider is the split-button convention (label and chevron do different things), so it misleads when the whole button opens the menu. class_ {string} Extra classes on the trigger, e.g. "w-full sm:w-auto". wrapper_class {string} Extra classes on the .dropdown-menu element that wraps the trigger. Width classes need to be on BOTH this and class_: the wrapper is shrink-to-fit, so a `w-full` trigger inside a default wrapper still only reaches its own content width. #} {% from "basecoat/dropdown-menu.html.jinja" import dropdown_menu %} {% macro action_menu(id, items, label="Action", align="end", variant="outline", size="sm", icon=None, divider=true, class_="", wrapper_class="") %} {{ dropdown_menu( id=id, main_attrs={"class": wrapper_class}, trigger=(icon if icon else '') ~ '' ~ label ~ '' ~ ('' if divider else '') ~ '', trigger_attrs={"class": ("btn " ~ class_) | trim, "data-variant": variant, "data-size": size}, popover_attrs={"data-align": align}, items=items ) }} {% endmacro %}
